## 👋 반가워요!

```diff
+ 동네에서 감튀 같이 먹을 사람이 없어서 → 감튀모임 지도를 만들었고
+ 청년 정책이 너무 흩어져 있어서 → Matchy를 만들었고
+ 방학마다 비는 기숙사가 아까워서 → SB Stay를 만들었어요
```

- 🌱 **Spring 백엔드**로 시작해서, 지금은 **Next.js · FastAPI · AI**까지 풀스택으로 굴러가는 중
- 🏃 해커톤·공모전 단골이에요. "이거 있으면 좋겠다"를 **실제로 쓸 수 있는 서비스**로 만드는 걸 제일 좋아해요
